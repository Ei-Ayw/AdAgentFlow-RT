论文叙事应以这个版本为准：

```text
AdAgentFlow-RT is a contractual runtime for reliable high-throughput long-horizon multi-agent workflows.

The paper does not introduce a new task dataset. It layers a production-stress evaluation harness on top of public benchmark task fixtures, especially tau3/tau2-style tasks and AgentChangeBench-style goal-change tasks.

The core claim is runtime reliability: under concurrent execution and injected faults, the runtime keeps failures bounded, diagnosable, traceable, and recoverable, instead of only reporting whether an agent completed a task.
```
