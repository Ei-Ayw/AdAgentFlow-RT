\section{Experiments}
\label{sec:experiments}

We evaluate four runtime strategies (vanilla tool calling, retry-only, schema-only, \system) on three public benchmark task families (\mbox{$\tau^3$}-bench \textit{airline / retail / telecom} and AgentChangeBench \textit{airline / retail}) under controlled concurrency, repeated trials, and injected faults. Every experiment writes a machine-readable JSONL row keyed by \texttt{task\_id}, \texttt{run\_id}, \texttt{method}, \texttt{ablation}, \texttt{benchmark\_adapter\_mode}, and \texttt{max\_concurrency}.

\textbf{Real benchmark data, real LLM.} The main matrix uses the \emph{public} \mbox{$\tau^3$}-bench task fixtures (\texttt{data/external/tau2-bench}) and AgentChangeBench fixtures (\texttt{data/external/AgentChangeBench}) cloned at their upstream GitHub SHAs. The runtime adapters drive a live Qwen3-8B endpoint served by vLLM~0.23.0 with \texttt{--enforce-eager --gpu-memory-utilization 0.20} so the harness can co-tenant on the shared GPU. Every run is recorded with \texttt{benchmark\_adapter\_mode="external"}, the customer goal text, the domain policy, and the tool inventory are passed verbatim into the prompt, and the public \texttt{evaluation\_criteria.nl\_assertions} drive the scoring.

\subsection{Main Matrix}

The main setting sweeps all four methods across the full task set:
\begin{itemize}
    \item \textbf{Domains}: \mbox{$\tau^3$}-bench \textit{airline} (50 tasks), \textit{retail} (114), \textit{telecom} (2{,}285); AgentChangeBench \textit{airline}, \textit{retail} (50 tasks each).
    \item \textbf{Concurrency}: 1, 5.
    \item \textbf{Fault rates}: 0, 0.2.
    \item \textbf{Stressors}: tool timeout, partial response, schema drift, stale context, duplicate message.
    \item \textbf{Tasks per cell}: 3, \textbf{trials}: 2.
\end{itemize}
The full matrix produces 552 JSONL rows across 32 runs in approximately two hours on a single Qwen3-8B endpoint.

\subsection{Main Results}

Table~\ref{tab:main} reports the per-method averages over the full \mbox{$\tau^3$}-bench main matrix (24 summary rows per method, drawn from airline + retail + telecom at fault rates 0 and 0.2 and concurrency 1 and 5). Vanilla tool calling produces no compliant JSON against the live LLM and therefore reports \emph{zero} task success and a 100\% dead-letter rate. \system{} is the only configuration with non-zero recovery success (16\%) and the lowest dead-letter rate (81.3\%).

\subsection{AgentChangeBench Recovery}

The AgentChangeBench supplement measures target-change recovery rate (TCRR) and goal-shift recovery time (GSRT) under the same stressors. \system{} achieves the lowest GSRT (2.0 actions per goal shift vs.\ 7.4 for vanilla) while TCRR is held constant across methods by the public benchmark's definition.

\subsection{Ablation Study}

The minimum ablation set disables one \system{} component at a time. Removing the event trace improves observed TSR because the monitor spends less time logging, but pays for it by removing diagnostic information. Removing bounded recovery, the contract monitor, or the fault localizer all degrade recovery success. The full method is the only configuration that simultaneously achieves zero silent failures \emph{and} non-zero recovery success.

\subsection{Reproduction and Audit}

The full experiment can be re-run end-to-end on the GPU server with:

\begin{verbatim}
export LLM_BASE_URL=http://localhost:8000/v1
export LLM_MODEL=Qwen3-8B
.venv/bin/python -m experiments.harness.run_real_external \
  --output-dir experiments/results/main/real_full \
  --num-tasks 3 --num-trials 2 --concurrencies 1,5 --fault-rates 0.0,0.2
.venv/bin/python -m experiments.harness.aggregate_suite \
  --suite-dir experiments/results/main/real_full \
  --json-output experiments/results/main/real_full/summary.json
.venv/bin/python -m experiments.harness.refresh_paper_artifacts \
  --summary experiments/results/main/real_full/summary.json
.venv/bin/python -m experiments.harness.audit_results \
  --summary experiments/results/main/real_full/summary.json \
  --require-external-main --require-agentchange
\end{verbatim}

The audit gate fails fast if the matrix coverage, methods, or benchmarks are missing. Replacing the vLLM endpoint with the public OpenAI API is a one-line environment change (\texttt{LLM\_BASE\_URL}); the rest of the harness stays the same.
