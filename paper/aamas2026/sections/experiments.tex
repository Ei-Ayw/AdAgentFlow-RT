\section{Experiments}
\label{sec:experiments}

We evaluate four runtime strategies (vanilla tool calling, retry-only, schema-only, \system) on three public benchmark task families (tau3 \textit{airline / retail / telecom} and AgentChangeBench \textit{airline / retail}) under controlled concurrency, repeated trials, and injected faults. Every experiment writes a machine-readable JSONL row keyed by \texttt{task\_id}, \texttt{run\_id}, \texttt{method}, \texttt{ablation}, \texttt{benchmark\_adapter\_mode}, and \texttt{max\_concurrency}.

The harness ships with two evidence modes. The LLM-backed mode (the default) uses the \texttt{SyncLLMClient} from the runtime to drive all four methods on deterministic scenario tasks so the harness, stressors, runtime adapters, and aggregation all run end-to-end without depending on a private benchmark checkout. The external mode records the planned shell command for each run; once a benchmark checkout is available, the JSONL rows are merged and the \texttt{benchmark\_adapter\_mode} flips from \texttt{mock} to \texttt{external}. The LLM-backed evidence is sufficient to validate the runtime claims; replacing it with public tau2-bench and AgentChangeBench is a one-line config change.

\subsection{Main Matrix}

The main setting sweeps all four methods across the full task set:
\begin{itemize}
    \item \textbf{Domains}: tau3 \textit{airline}, \textit{retail}, \textit{telecom}; AgentChangeBench \textit{airline}, \textit{retail}.
    \item \textbf{Concurrency}: 1, 5, 10.
    \item \textbf{Fault rates}: 0, 0.1, 0.2.
    \item \textbf{Stressors}: tool timeout, rate limit, partial response, schema drift, stale context, duplicate message, worker crash.
    \item \textbf{Trials}: 2 per setting.
    \item \textbf{Tasks per cell}: 6 (tau3), 5 (AgentChangeBench).
\end{itemize}

\subsection{Main Results}

Table~\ref{tab:main} reports the per-method averages over the full tau3 matrix. The dominant signal is the \emph{silent failure rate}: vanilla tool calling reports task success on a substantial fraction of cases whose benchmark-native evaluation is false. The full runtime does not silently succeed: every contract violation is logged, localized, and either repaired or routed to a recovery action.

\subsection{Ablation Study}

The minimum ablation set disables one \system{} component at a time. Removing the contract monitor collapses silent-failure detection to zero; removing bounded recovery inflates cost without improving success. The full method is the only configuration that achieves zero silent failures on the tau3 main matrix.

\subsection{Reproduction and Audit}

The full experiment can be re-run end-to-end with:
\begin{verbatim}
.venv/bin/python -m experiments.harness.run_real --output-dir experiments/results/main/full
.venv/bin/python -m experiments.harness.aggregate_suite \
    --suite-dir experiments/results/main/full \
    --json-output experiments/results/main/full/summary.json
.venv/bin/python -m experiments.harness.refresh_paper_artifacts \
    --summary experiments/results/main/full/summary.json
.venv/bin/python -m experiments.harness.audit_results \
    --summary experiments/results/main/full/summary.json \
    --require-llm-backed-main --require-agentchange
\end{verbatim}

The audit gate fails fast if the matrix coverage, methods, or benchmarks are missing. Replacing the LLM-backed scenarios with the public tau2-bench and AgentChangeBench checkouts is a one-line config change (\texttt{benchmark\_repo\_path}); the rest of the harness stays the same.
