# ADR-0004：当前企业级能力边界

- 状态：已采纳
- 日期：2026-07-14

## 背景

项目目标是证明 Agent 长任务的可靠执行，而不是一次性构建完整广告投放平台。多租户、RBAC、多地域、服务网格、Ray 和 Kafka 都可能增加“架构感”，但没有真实约束时难以验证价值。

## 决策

当前优先保证单区域、单组织场景中的幂等、重试、恢复、审计、迁移、观测和真实基础设施测试。暂不实现多租户、计费、跨地域容灾、复杂微服务拆分、Redis/RabbitMQ 集群和自动模型路由。

## 代价

项目不能被描述为已满足大型企业生产要求；安全治理、SLA、容量和组织权限仍有明确缺口。

## 重新评估条件

出现真实用户隔离、团队协作、合规要求、明确 SLA 或经过压测证明的单点瓶颈时，以新 ADR 引入对应能力。
